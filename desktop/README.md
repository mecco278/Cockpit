# Cockpit Windows 桌面版 1.0.1

双击 `Cockpit-1.0.1-win-x64-setup.exe`，按安装向导完成安装。程序默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Cockpit`，通过开始菜单或安装时选择创建的桌面快捷方式启动。应用直接读取随包附带的界面资源，无需启动本地服务或安装 Node.js。[直接下载 Windows 安装程序](https://github.com/mecco278/Cockpit/releases/download/v1.0.1/Cockpit-1.0.1-win-x64-setup.exe)

新的工作空间从零个项目开始。从旧便携版切换前，先退出旧程序，新版会读取同一个本机工作空间。可在 Windows「设置 → 应用 → 已安装的应用」里卸载。卸载会保留工作空间与备份。

## 进度记录

打开「进度记录」，在原记录的「查看详情」旁点「编辑」，可以修改标题、成果、阻碍和下一步，原始记录时间、所属项目与关联行动会保留。新增或移除阻碍文字后，记录的类型随内容更新。

## 进展回顾

打开「进展回顾」，选好项目和参考日期。点击「周进展」或「月进展」切换明细，可前后翻周或翻月，点开完成行动和进展记录。两种范围都按实际完成日期和记录日期统计。先展示进展与阻碍，再展示当前可推进的已有行动，后者可直接加入今日。进行中项目的阻碍记录填有「下一步」时，可点「转为待办行动」，在原项目创建待办并从行动详情回查记录。同一记录已转为行动时，按钮改为查看已有行动。

点日期范围下方的「查看周复盘与调整历史」，可直接跳到快照区。每周快照从手动记录的「下一步」提取最多一项行动草稿，跳过关联行动还没完成、来源已处理或已转为待办的记录。草稿可核对原记录、修改后采纳，或暂不采纳。

## 新增项目与日历

新增项目只需填写名称，目标、完成标准和首个行动都可以选填。日历用蓝色旗帜标记实际创建日，项目完成后变为红色小旗。单项行动完成使用普通勾号。同日创建和完成会合为一条，不同日会分别显示创建与实际完成。早期项目缺少创建时间时，仅展示已有日期记录。

从项目页点「项目日历」，可直接定位到创建日或实际完成日。项目完成以项目页的「完成项目」确认为准。

日历内置 2026 和 2027 年的常见节日及中国大陆放假调休安排。节日名称与「休／班」单独显示。元旦、劳动节和国庆节等固定公历日期也会在其他年份标记。 [2026 年放假安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html) · [2027 年放假安排](https://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/content/202611/content_7085101.htm) · [香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)

## 自定义工作台

点「自定义工作台 → 摆放小组件」，拖卡片标题到任意网格位置，或拖右下角改变宽高。移动中显示落点轮廓，松手时才调整有重叠的卡片。空白格可以保留。标题和右下角手柄支持方向键，卡片设置按钮也可直接输入行列和宽高。坐标、尺寸与配色保存在本机。窄窗口默认使用紧凑视图和图标侧栏。可以展开侧栏，或用「查看摆放」查看原始网格。两种视图共用本机坐标。用「自定义工作台」开关可选组件。

「今日容量」把今天已完成行动的估时和今日重点的预计时间加在一起，显示与当天可用时间的差额。未估时的行动单独计数。可用时间按当天设置，在「自定义工作台」可开关今日容量和近七天记录节奏。

「今日重点」的优先级保留文字和卡片左侧色条。悬停行动行或用键盘聚焦时，会显示「记进展」和更多操作；圆形按钮用于完成并记录。收工清单折叠时预览前两项。待跟进日期用青蓝色时钟区分于截止预警。

在行动详情点「设置跟进日期」，或在工作台的「待跟进」卡片内改日期。今天和已到期的事项排在未来日期前，未设置日期的等待事项排在最后。可在「自定义工作台」开关待跟进。

「收工清单」集中显示今日尚未完成的行动。展开后逐项选「明天再做」「退回待办」或「转为等待」，每项立即保存。明天再做会在次日进入今日重点，隔天才打开时仍会显示。可在「自定义工作台」关闭收工清单。

点击顶栏「全局搜索」或按 `Ctrl+K`，输入关键词即可搜索项目、行动、进展记录和便签，点击结果可打开原内容。方向键可选结果，回车打开。

## 随手记

在工作台点「记想法」可快速写一条便签。在侧栏「随手记」白板可新建、查看、编辑或删除便签。标题选填，便签独立于项目，随本机工作空间一起备份和恢复。

便签卡片上的「转为项目」会预填项目名称和说明。无标题的便签取正文第一行作为名称。确认后打开新项目的「项目说明」，原便签保留并显示「查看项目」。

## 行动树与思维导图

左侧「行动树」默认铺满内容区，打开项目时显示前两层任务。点击「展开全部」可看更多分支，点击「前两层」回到默认视图。点「并排对照」同时打开第二个项目，两个窗格各占一半，可独立平移、缩放及展开分支。窄窗口下上下显示。点击任务节点查看详情，已完成的节点与连线会点亮。项目详情里的「行动树」标签也可进入，标签支持左右方向键切换。

行动树窗格内的「紧凑视图」缩小节点，只保留状态图标、标题、完成比与必要的分支开关。悬停或聚焦节点时，会高亮它通往上级和已展开下级的连线。层级较多时可结合「适应窗口」和拖动画布查看。

左侧「思维导图」提供独立画布。文献卡可以记录 DOI、链接或引文。按住 Shift 点击卡片可多选，常驻的「新建分组」在选中至少两张时可用。聚焦卡片后用 Alt+Enter 快速加子分支，Ctrl+Enter 加同级卡片。双击空白处新建节点，双击已有卡片就地编辑标题和内容。可拖动卡片位置和右下角尺寸手柄。把卡片边缘的圆点拉到另一张卡片即可连线，拉到空白处可新建相连节点。「管理连线」可添加说明或移除连线，说明以水平白底标签展示。选中想法卡后可用「转为项目行动」选择所属项目，确认标题和说明后加入待办。行动详情可打开并定位到来源导图。拖动画布空白处可平移，按住 Ctrl 滚动可围绕指针缩放，「全图」将内容缩放到可见范围。导图随本机工作空间一起备份和恢复。

## 查看项目行动树

从左侧「我的项目」打开项目，点击标题旁的「查看项目行动树」，或选择「行动树」标签。节点图支持点击节点查看详情、缩放、拖动和折叠，完成的节点及连线会点亮。图内可以切换到折叠列表。

## 带入浏览器数据

1. 用原来保存项目的浏览器打开旧原型，选择「数据与体验 → 导出体验备份」保存 JSON。
2. 在 Windows 版左侧选择「数据与备份 → 导入 JSON 备份」。选择文件后，核对项目、行动、进展和复盘数量。
3. 选择「确认恢复备份」。确认后会替换桌面工作空间，替换前会先备份桌面现有数据。原浏览器中的项目仍保留。建议先迁移再开始用桌面版记录真实项目，以免分成两套数据。

导入支持原型导出的 v1–v3 备份和桌面版导出的备份。当前支持整份恢复。备份校验不通过、预览后现有数据变化或安全副本写入失败时，不会替换现有项目。

## 数据与备份

- 日常数据保存在 `%LOCALAPPDATA%\Cockpit\workspace.sqlite`。应用程序和项目数据分开存放。
- 自动备份位于 `%LOCALAPPDATA%\Cockpit\backups`。已有数据时，每天首次打开或保存会生成当日副本，最多保留最近 14 份。手动备份和替换前的安全副本不会随每日副本轮换清理。当前工作空间的 JSON 备份上限为 16 MB。
- 「数据与备份」显示最近成功备份时间，可以立即备份、打开备份文件夹，或把副本导出到自己选择的位置。若希望电脑或磁盘出故障后也能恢复，请把一份导出保存在另一块盘上。
- 「数据与备份 → 清空工作空间」会先保留本机备份，再回到空白状态。
- 恢复时，在同一菜单选择备份文件即可。桌面工作空间无法打开时，先关闭 Cockpit 并保留整个 `%LOCALAPPDATA%\Cockpit` 文件夹；不要删除数据库。可将旧目录另行保存，再启动以创建新目录，从旧目录 `backups` 中恢复一份有效备份。
- 更新应用时退出正在运行的 Cockpit，再运行新版安装程序。

截止提醒在应用内显示。每周复盘使用本地规则。

工作空间和导出的 JSON 由本机账户的文件访问权限保护，应用未额外加密。备份中的 SHA-256 用于检验内容完整性；仅导入来自可信来源的项目备份。

## 构建与验证

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\desktop\build.ps1
npm test --prefix desktop
npm test --prefix prototype
```

构建脚本固定 Electron 版本并校验运行时压缩包。已有压缩包可通过 `-RuntimeArchive` 指定。单元测试需要 Node.js 24 或更高版本。

如需打包发布，安装 Inno Setup 7，再从仓库根目录运行下列命令。如果编译器位于其他目录，可用 `-CompilerPath` 指定 `ISCC.exe`。脚本从源码构建，并在 `dist` 生成 `Cockpit-1.0.1-win-x64-setup.exe` 和对应的 `.sha256` 文件。[Inno Setup 下载](https://jrsoftware.org/inno-setup/downloads)

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\desktop\build-installer.ps1
```

打包后的应用可通过 Playwright 验证。准备 Playwright 包后，运行 `node .\desktop\tests\desktop.browser.mjs --playwright-path 'Playwright 包目录'`。测试用独立临时目录保存数据。可附加 `--previous-exe '旧版 Cockpit.exe 路径'` 验证读取旧版工作空间。
