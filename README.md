# Cockpit

Cockpit 是一款在 Windows 上本机运行的个人项目管理工具。把计划、行动、进展记录和复盘放在一起，适合同时推进多个项目。

## 下载与启动

在本仓库的 Releases 下载 `Cockpit-1.0.0-win-x64.zip`。完整解压后双击 `Cockpit.exe`。这是 64 位 Windows 便携版，运行时无需另装 Node.js 或启动网页服务。首次打开是空白工作空间，在今日工作台点击「创建首个项目」即可开始。

从旧版升级时，先关闭 Cockpit，再打开新版。工作空间保存在 `%LOCALAPPDATA%\Cockpit`，新版会继续读取这个目录。已有的浏览器数据可以先导出 JSON，再从 Windows 版「数据与备份」导入。

## 功能

- **今日工作台**可跨项目安排行动，检查容量、截止和待跟进，收工时逐项处理未完成事项。小组件可以移动、调整尺寸、换色或隐藏。
- **项目和行动树**支持看板、紧急程度、分层拆解和完成进度。行动树可折叠、缩放，并排对照两个项目。
- **进度记录与回顾**支持编辑原记录、查看周月进展，从阻碍记录创建待办，或保存基于本地规则的周复盘。
- **思维导图和随手记**支持文献卡、自由连线、分组和来源回查。想法卡可转为项目行动，便签可转为项目。
- **日历与搜索**可查看项目创建、实际完成日和截止安排，并搜索项目、行动、进展记录和便签。
- **本机数据与备份**使用 SQLite 存储，支持每日自动备份、手动导出、预览和恢复备份。

截止提醒在应用内显示。日历内置 2026 和 2027 年的中国大陆放假调休安排。周复盘在本地运行。

## 从源码构建

在 Windows 上从仓库根目录运行以下命令。构建脚本下载并校验固定版本的 Electron 运行时。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\desktop\build.ps1
```

完成后可双击 `打开Cockpit.cmd`，或直接打开 `dist\Cockpit-1.0.0-win-x64\Cockpit.exe`。
